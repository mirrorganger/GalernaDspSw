# Galerna DSP Software

Firmware for the Galerna DSP audio PCB board.

## Related repositories

- Hardware / KiCad project: https://github.com/mirrorganger/GalernaDsp

## Project goals

- Keep the STM32CubeMX-generated firmware structure intact.
- Add Galerna-owned application logic as a modern C++20 layer.
- Prefer test-driven development for project-owned C++ code.
- Keep builds reproducible through Docker / devcontainer workflows.

## Architecture notes

- `Core/` and `Drivers/` are STM32CubeMX / STM32 HAL generated or vendor-owned code.
- `cmake/stm32cubemx/` contains CubeMX-generated CMake integration.
- `Application/` is the C/C++ bridge called from CubeMX `main.c`.
- `Galerna/` contains project-owned C++ app, drivers, effects, HAL concepts, and STM32 platform adapters.
- `Tests/` contains host-side Catch2 tests for project-owned C++ code.

## Build and test workflow

Prefer CMake workflow presets:

- Host tests: `cmake --workflow --preset host-debug-build-and-test`
- STM32 debug firmware: `cmake --workflow --preset stm32-debug-build`
- STM32 release firmware: `cmake --workflow --preset stm32-release-build`

Builds are expected to work inside the Docker/devcontainer environment.

## Development conventions

- Use C++20 for project-owned C++ code.
- Keep hardware-independent logic testable on the host.
- Use concepts and dependency injection for HAL-facing drivers where practical.
- Do not casually edit CubeMX/vendor-generated files unless the task specifically requires it.
- Verify changes with the narrowest relevant build or test command before reporting completion.
