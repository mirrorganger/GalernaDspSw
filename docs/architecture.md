# Galerna DSP Software Architecture

This project keeps the STM32CubeMX generated firmware structure and adds a modern C++ Galerna layer.

## Vendor-scaffolded files

Originally generated by STM32CubeMX, now hand-maintained as ordinary firmware source
(the `.ioc` project has been retired — see `docs/cubemx/README.md`):

- `Core/`
- `Drivers/`
- `cmake/stm32cubemx/`
- `startup_stm32f405xx.s`
- `STM32F405XX_FLASH.ld`
- `cmake/gcc-arm-none-eabi.cmake`

## Galerna-owned files

- `Applications/<Name>/app.cpp`: one independently-buildable, independently-flashable
  firmware "app" per subdirectory (e.g. `Applications/ThxDeepNote/`,
  `Applications/PotBlink/`). Each wires up the concrete hardware objects it needs and
  provides the `App_Init`/`App_Tick` C-ABI entry points `Core/Src/main.c` calls -- the same
  two entry points, unchanged, regardless of which app is linked in. Add a new app by adding
  a new `Applications/<Name>/app.cpp` and a `galerna_add_app(<Name>)` call in the top-level
  `CMakeLists.txt`; see that file's `galerna_add_app()` function.
- `Application/`: small pieces shared by every app: `Inc/app.h` (the `App_Init`/`App_Tick`
  declarations) and `Src/swo_debug.cpp` (SWO `printf` plumbing).
- `Galerna/Core/`: platform-independent DSP primitives.
- `Galerna/Drivers/`: device drivers using concepts and template dependency injection.
- `Galerna/Effects/`: DSP effects.
- `Galerna/App/`: product-level Galerna logic -- one host-testable `init()`/`tick()` class
  per app (e.g. `GalernaApp.hpp`, `ThxDeepNoteApp.hpp`), instantiated by that app's
  `Applications/<Name>/app.cpp` with the real STM32 hardware objects.
- `Galerna/Platform/Stm32F405/`: STM32-specific adapters over HAL.
- `Tests/`: host-side Catch2 tests.

## Build commands

STM32 firmware -- builds every app target (one `.elf`/`.bin`/`.hex` per
`Applications/<Name>/`, e.g. `ThxDeepNote`, `PotBlink`); add `--target <Name>` to build just
one:

```bash
cmake --preset Debug
cmake --build --preset Debug

cmake --preset Release
cmake --build --preset Release
```

Host tests:

```bash
cmake --preset host-debug
cmake --build --preset host-debug
ctest --preset host-debug
```
